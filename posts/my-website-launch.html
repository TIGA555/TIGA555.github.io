我的个人网站上线啦

2026 年 8 月 31 日 · 3 分钟阅读

一直以来都想做一个属于自己的个人网站，把做过的东西、学到的知识记录下来。今天，这个想法终于落地了——网站正式上线，任何人都可以通过 https://tiga555.github.io 访问。

为什么想做个人网站

一方面是给自己一个"数字名片"：把我的项目、技能和经历放在一个地方，朋友或未来的合作者可以快速了解我；另一方面是给自己一个持续输出的空间，把学习过程中的思考沉淀下来，而不是学完就忘。

网站是怎么做出来的

整个网站是纯静态的，用 HTML、CSS 和 JavaScript 从零写起，没有使用复杂的框架。结构包含：关于我、技能、作品、博客和联系方式几个板块，还做了深浅色模式切换和手机适配。

部署方面选择了 GitHub Pages——免费、无需服务器，把代码推送到 GitHub 仓库，网站就会自动更新。这对个人静态网站来说非常合适。

过程中踩过的坑

最大的坑其实是网络问题：国内直连 GitHub 经常连接超时，推送代码一直失败。本地开着的代理工具可以正常访问 GitHub，让 Git 走代理后一次就成功了。

另外一个小坑是刚开始不小心进入了 GitHub 的"导入仓库"页面，按钮变成了 Begin import，和"新建仓库"的 Create repository 不是一回事，差点创建错。遇到不懂的页面，多看两眼再点总没错。
